# Arquivo histórico da documentação

Esta área preserva decisões e checkpoints antigos sem poluir a documentação vigente.

## Estrutura

- `checkpoints/`: entregas cronológicas 04–88 e registros técnicos antigos.
- `legacy-plans/`: planos iniciais substituídos pela arquitetura atual.

O conteúdo histórico pode citar comandos, regras, targets, animações ou gifts que já não representam o jogo atual. Cada arquivo possui um aviso de arquivo e links de retorno à documentação vigente.

Para desenvolver o projeto hoje, comece em [`../README.md`](../README.md).

Nada nesta pasta deve ser tratado como requisito vigente sem confirmação nos documentos atuais ou nas specs ativas.
